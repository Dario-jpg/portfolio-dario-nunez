# Portfolio Personal — Darío Núñez de Arenas

## Descripción

Este proyecto es mi portfolio personal desarrollado como práctica de 1.º DAM. En esta página muestro información sobre mí, mis habilidades técnicas, formación y algunos proyectos realizados durante mi formación en informática.

El objetivo de este portfolio es disponer de una web profesional propia donde presentar mi perfil y seguir mejorándola en el futuro.

Elegí esta paleta porque quería un diseño moderno con tonos oscuros y detalles en morado para dar una estética tecnológica y profesional.

---

## Elemento diferenciador

El portfolio incluye un sistema de modo oscuro y modo claro implementado con JavaScript y variables CSS. Elegí este elemento porque mejora la experiencia visual y permite personalizar la apariencia de la página.

---

## Uso de IA

He utilizado herramientas de IA como ChatGPT para resolver dudas de diseño, estructura HTML, estilos CSS y organización visual del portfolio. Todo el contenido personal, proyectos y datos incluidos son reales y revisados por mí.

---

## Dificultades encontradas

Una de las principales dificultades fue adaptar correctamente la página a dispositivos móviles y organizar visualmente las tarjetas de proyectos y habilidades.

También tuve problemas con las rutas de imágenes y la publicación en GitHub Pages, que solucioné revisando la estructura de carpetas y la configuración del repositorio.
